## Getting Started (instructions amont)

1. Clone Repository:

```bash
git clone https://github.com/themewagon/shadcn-admin.git
```

2. Install Dependencies:

```bash
npm i
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
